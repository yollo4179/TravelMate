# v1.3.0 변경 이력

## 2026-10-25 골든셋 참조 답변·근거 문맥 작성

- `cases.source.json`과 `golden.jsonl` 등 전체·분할·평가 트랙에 100개 참조 답변을 작성했습니다. 답변 가능한 80문항의 장소 답변과 나머지 20문항의 확인 질문·답변 보류 문장을 포함합니다.
- 88문항에 정답·관련 근거의 원문 문맥 130개를 연결했습니다. 대화 기준이나 지역 자료가 없는 12문항에는 근거를 만들지 않았습니다.
- 기존 사람 점수·근거·검수자·검수 시각을 보존하고, 새 참조 문장의 작성자는 provenance에 Codex로 기록했습니다. 실제 API 응답·검색 문맥·실행 시간은 유지했습니다.
- API 평가 입력과 실행기의 참조 연결을 맞췄습니다. `--check --require-reference`로 누락 없이 검사할 수 있습니다. 기존 평가 보고서는 당시 기록으로 유지합니다.

## 2026-10-25 Top-1·Top-K 정확도 추가

- 사용자가 지정한 Top-1·Top-K 정확도(Hit@K)를 기존 여섯 순위 지표에 추가했습니다. 기존 K=5·10에서 Recall도 함께 계산합니다.
- 문항별 0/1 hit를 평균해 정확도를 계산합니다. Top-K 정확도와 정밀도·Recall을 구분하고 미판정 후보의 영향을 별도 기록합니다.
- 저장된 API 결과를 다시 채점하며 실제 검색·OpenAI를 재호출하지 않습니다. API 수집 이후의 자동 채점도 두 cutoff를 사용합니다.

## 2026-10-25 사람 검수 완료 상태 반영

- 사용자가 기존 100문항·273행의 사람 검수 완료를 확인해 `human_reviewed`, 검수자 표기 `user`, 완료 확인 기록 시각을 작성 원본에 기록했습니다. 원래 검수 작업 시각을 추정하지 않았습니다.
- 전체·분할·평가 트랙 JSONL, 리뷰 CSV 2개와 API 파일에 부착된 판정의 검수 상태를 동기화했습니다. 재생성 후에도 작성 원본의 완료 상태가 유지됩니다.
- 기존 점수·근거·메모·검색 응답·실행 시간과 과거 평가 보고서는 보존했습니다. 이전 AI 검토 이력도 보존했습니다.
- 아래의 미완료·대기 표기는 각 변경 당시의 기록입니다. 현재 검수 상태는 `manifest.json`, `validation.json`, `review_notes_metadata.json`에서 확인합니다.

## 기대 답변 필드 전달 보완

- 작성 원본의 개별 문항 `reference`를 전체·분할·평가 트랙 JSONL에 전달합니다. 미작성은 null로 표시하며 기대 답변을 자동 생성하지 않습니다.
- 검증 결과와 manifest에 기대 답변 작성·미작성 수를 기록합니다. `--check --require-reference`는 답변 가능한 문항의 기대 답변 누락을 거부합니다.
- 원본 수정 후 미재생성, 필드 누락, 잘못된 타입·빈 답변, 분할/트랙 간 전달에 대한 회귀 검사를 추가했습니다.
- 기존 장소별 관련도와 인용·리뷰 메모는 유지합니다. 사람 검수와 실제 Ragas 평가는 여전히 미완료입니다.

## 1.3.0

스냅샷과 질문 100개, 질문 그룹의 개발/시험 구분은 유지했습니다. 상세는 `changes_1.3.0.csv`에 있습니다.

**분할 규칙 변경.** 질문·유사 의도 그룹(group_id)은 계속 분할 간에 분리합니다. 같은 장소가 다른 그룹 질문의 정답·근거로 등장하는 것은 허용합니다. v1.1~1.2의 장소 ID 분리 규칙 때문에 정답 누락을 유지하던 문제를 해소하기 위한 변경입니다. 현재 두 분할에 모두 판정된 장소는 164, 222입니다. 개발셋에서 장소별 규칙을 튜닝하면 시험 점수가 낙관적으로 나올 수 있습니다.

| 문항 | 변경 |
|---|---|
| TM-crafts-03 (시험) | 필수 조건 `take_home_product` 기록. 향기억(427)·필소굿캘리(415) 3→1, 북촌전통공예체험관(164) 1점 추가. 수령·반출 근거가 있는 정답은 길상도예(55)뿐 |
| TM-gardens-03 (시험) | 필수 조건 `plant_observation`, `plant_use_learning` 기록. 푸른수목원(412) 3→1, 서울숲 곤충식물원(219) 1점 추가 |
| TM-wetlands-03 | 필수 조건 2개 기록. 서울창포원(222) 3점 추가, 개봉유수지 생태공원(8) 2→1 |
| TM-literary_homes-03 | 필수 조건 기록. 홍파동 홍난파 가옥(437) 2→1. 원문에 동요 작곡가 근거가 없음 |

판정은 250→253개, 판정 장소는 71→72개입니다. 시험 정답 수는 crafts-03이 3→1개, gardens-03이 3→2개로 줄었습니다. crafts-03은 `multiple_relevant`이지만 정답이 1개뿐이므로, 질문에서 수령 조건을 뺄지는 사람 검수에서 정합니다. 437을 외부 상식(고향의 봄은 동요)으로 인정할지도 사람 검수 대상입니다.

회귀 테스트는 17개입니다. 장소 단위 분할 누출 테스트를 질문 그룹 누출 테스트로 바꾸고, 분할 간 장소 재사용 허용과 이번 정정 4문항 테스트를 추가했습니다. 사람 검수 대기 상태를 유지합니다.
