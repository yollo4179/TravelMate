# 여행 AI 앱 UI/UX 화면 구조 정리 (개선안 v1.1)

> **목적**: 사용자의 원래 기획(의미기반 검색, 마커 선택에 따른 추천 분기, 개인 마커 관리, context 유지, tool calling, 상세 계획 세우기 등)을 최대한 반영하면서,  
> **UX 개선** (컨텍스트 명확성, 단계 감소, 시각적 구분, Bottom Sheet 적극 활용 + **근처 활동 키워드 검색**, **현재 수정중인 계획 표시 및 챗봇 동기화**)을 적용한 화면 구조 문서입니다.

**업데이트 내용 (v1.1)**
- 지도 화면에 **근처 활동 키워드 검색 기능** 추가 (임시 핀 생성)
- **현재 수정중인 계획 표시** 및 **챗봇과 실시간 동기화** 기능 설계
- Context 상태에 `currentEditingPlan` 추가

---

## 전체 네비게이션 구조 (Bottom Navigation 추천)

```
지도 (Map)  |  AI 채팅 (Chat)  |  내 일정 (Schedules)  |  프로필 (Profile)
```

- **지도** = 메인 작업 허브 (검색, 마커 관리, 추천, 근처 활동 검색 대부분 처리)
- **AI 채팅** = 자연어 추천 전문 화면 (지도의 현재 수정중인 계획과 동기화)
- **내 일정** = 완료된/진행 중 계획 목록 관리
- 프로필 = 선택

**핵심 원칙**
- 지도를 중심으로 대부분의 작업이 이루어지도록 설계
- Context(현재 포커스 + **수정중인 계획**)를 항상 명확히 표시
- Bottom Sheet를 적극 활용해 지도 컨텍스트 유지
- 핀 타입(개인/임시/확정)을 시각적으로 명확히 구분
- Map ↔ Chat 간 상태 동기화로 끊김 없는 경험 제공

## 1. 지도 화면 (MapScreen) — 가장 중요한 화면

### 주요 역할
- 장소 탐색, 마커 관리, AI 추천, **근처 활동 키워드 검색**의 중심 공간
- 사용자가 “마커 하나 선택했는지 여부”에 따라 동작이 달라지는 요구사항을 명확하게 지원
- 검색/근처 검색 → 임시핀 생성 → 상세 계획으로 자연스럽게 연결
- **현재 수정중인 계획**을 시각적으로 표시하고 챗봇과 동기화

### 주요 컴포넌트 및 역할

| 컴포넌트                          | 역할                                                                 | 개선 포인트 (사용자 의견 반영) |
|-----------------------------------|----------------------------------------------------------------------|--------------------------------|
| **상단 검색바 + FilterChip 그룹** | 키워드 입력 + 카테고리 필터                                          | 의미기반 검색 + 필터 동시 적용 |
| **KakaoMap 뷰**                   | 지도 렌더링, 핀 표시, 제스처 처리                                    | 탭 = 선택, 길게 누르기 = 개인 마커 추가 |
| **상단 Context Chip / Bar** (고정) | 현재 활성 컨텍스트 + **"수정 중: [장소명] 상세 계획"** 배지 표시     | 사용자가 항상 상태를 인지 + Chat과 동기화 |
| **우측 하단 FAB 그룹**            | 내 위치 이동 / 마커 추가 / **근처 활동 찾기** / 채팅 열기            | "근처 활동 찾기" FAB 또는 마커 선택 시 나타나는 버튼으로 추가 |
| **Bottom Sheet (검색/추천 결과)** | 의미기반 검색 결과 또는 마커 근처 추천 목록 표시                     | 지도 조작 유지하면서 결과 확인 |
| **하단 Persistent Action Bar 또는 큰 FAB** | “상세 계획 세우기” Primary 버튼 (임시핀 존재 시)                   | 임시핀 생성 즉시 다음 액션 유도 |
| **핀 시각 구분**                  | 개인 마커(🔵), 임시 핀(🟡 점선 + “임시”), 확정 핀(🟢 + 번호)         | 세 종류 명확히 구분 |
| **키워드 입력 팝업 / Bottom Sheet** (신규) | 근처 활동 검색 시 키워드 입력 받는 모달                               | 지도 방해 최소화, 추천 키워드 칩 제공 |

### 마커 선택 로직 (사용자 요구 반영)
- **마커가 하나 선택**된 상태 → 해당 마커 중심으로 근처 추천 (키워드 없으면 최근 10개 정도)
- **마커가 선택되지 않은** 상태 → 키워드 의미기반 검색 (전체 또는 현재 지도 영역)
- 개인 마커 선택 시 → “이 마커 중심으로 추천” 모드 자동 적용 + 삭제/편집 메뉴 제공

### 근처 활동 키워드 검색 기능 (신규 — 결과는 임시 핀)

**목적**: 선택된 마커(또는 현재 위치) 근처에서 **키워드와 함께** 활동/장소를 찾고, 결과를 **임시 핀**으로 지도에 표시.

**동작 흐름**:
1. 마커 선택 또는 "근처 활동 찾기" FAB/버튼 클릭
2. **키워드 입력 팝업** 또는 전용 Bottom Sheet 열림
   - 입력 필드
   - 추천 키워드 칩 (도자기 체험, 역사 공부, 문화체험, 액티비티, 식당, 자연환경 등)
   - 빈 입력 허용 → 주변 추천 활동 자동 검색
3. 검색 실행 → 의미기반 + 위치 기반 **Hybrid Search** 수행 (RAG + PGVector)
4. 결과 처리:
   - 지도에 **임시 핀** 여러 개 표시 (🟡 노란색 점선 스타일)
   - Bottom Sheet에 결과 목록 표시
   - 각 결과 항목: “지도에서 보기” + “상세 계획 세우기” 버튼
5. 사용자가 임시 핀 클릭 또는 목록에서 선택 → 지도 이동 + 해당 임시 핀 강조 + “상세 계획 세우기” Primary 버튼 활성화

**특징**:
- 결과는 **항상 임시 핀**으로 생성 (확정하기 전까지는 계획에 영향 없음)
- 키워드 입력을 별도 팝업/시트로 분리해 지도 사용성 유지
- 검색 결과가 많을 경우 “더 보기”로 전체 후보 Bottom Sheet 확장 가능

### 현재 수정중인 계획 표시 및 챗봇 동기화 (신규)

**목적**: 사용자가 지도에서 임시 핀을 선택하고 상세 계획을 만들고 있는 상태를 명확히 보여주고, AI 채팅과 실시간으로 동기화.

**구현 방식**:
- **지도 화면 상단 Context Bar**에 **"수정 중: [장소명] 상세 계획"** 배지 또는 카드 표시
  - 배지 클릭 → 상세 계획 화면 바로 이동
  - “수정 완료” 또는 “취소” 버튼 제공
- 이 상태는 **전역 Context** (`currentEditingPlan` 또는 `activeTempPinForDetail`)로 관리
- **AI 채팅 화면** 상단 Context Bar와 **자동 동기화**
  - 지도에서 수정 중인 장소가 있으면 Chat 상단에 동일하게 표시
  - Chat에서 “이 장소 더 추천해줘”, “다른 활동 추천” 등의 메시지를 보내면 자동으로 지도의 현재 임시 핀 컨텍스트로 인식
- 반대로 Chat에서 추천 카드를 클릭하면 지도에 임시 핀 생성 + “수정 중” 상태 자동 활성화

**장점**:
- Map과 Chat 사이에 컨텍스트가 끊기지 않음
- 사용자가 “지금 어떤 계획을 만들고 있는지” 항상 인지 가능
- 포트폴리오 데모에서 **Context-aware + Cross-screen State Sync**를 강력하게 보여줄 수 있음

## 2. AI 채팅 화면 (ChatScreen)

### 주요 역할
- 자연어로 장소 추천 받기, Plan B 생성, 모르는 정보 요청 (tool calling + RAG)
- **지도의 현재 수정중인 계획**과 동기화
- 지도와 양방향 연결 (추천 카드 클릭 → 지도 임시 핀 + 수정 중 상태 활성화)

### 주요 컴포넌트 및 역할

| 컴포넌트                  | 역할                                                                 | 개선 포인트 |
|---------------------------|----------------------------------------------------------------------|-------------|
| **상단 Context Bar** (고정) | 현재 포커스 마커/위치 + **"수정 중: [장소] 상세 계획"** 표시         | 지도와 완전 동기화 (stateless 방지 핵심) |
| **채팅 메시지 영역** (LazyColumn) | 일반 대화 + AI 응답 + 추천 카드                                      | Tool calling 로딩 표시 |
| **추천 카드 Carousel**    | LLM 추천 장소 카드                                                     | 클릭 시 지도 이동 + 임시 핀 생성 + “수정 중” 상태 자동 활성화 |
| **입력 필드 + 전송 버튼** | 사용자 메시지 입력                                                   | 현재 수정중인 계획 context를 자동으로 포함해 전송 |

### 추가 고려사항
- 추천 카드에 “AI 분석 근거” 표시
- “이 장소에서 더 추천해줘” 질문 시 **지도의 현재 수정중인 임시 핀**을 자동 참조

## 공통 컴포넌트 및 패턴

### Context 관리 (전역 상태) — 업데이트
ViewModel에서 관리할 주요 상태:
- `currentFocusMarkerId`
- `activeContextType` (“marker” / “global”)
- `tempPins` (List)
- `confirmedPins`
- `personalMarkers`
- **`currentEditingPlan`** ← **신규**: 현재 상세 계획을 만들고 있는 임시 핀 ID 또는 장소 정보
- 채팅과 지도가 이 상태를 **실시간 공유** (StateFlow / SharedFlow 또는 동일 ViewModel)

### Bottom Sheet
- 장소 미리보기
- 추천 결과
- 전체 후보 목록
- 키워드 입력용 (근처 활동 검색 시)

### 핀 타입 Legend
- 개인 마커 / 임시 핀 / 확정 핀 시각 구분 설명

### Onboarding (선택)
- 지도 사용법 + 근처 활동 검색 방법 + Map ↔ Chat 동기화 설명

## 화면 간 주요 연결 흐름 (v1.1 업데이트)

1. **내 일정** → “새 계획 만들기” → **지도** (context 초기화)
2. **지도** 검색 또는 **근처 활동 키워드 검색** → **임시 핀** 생성 → “수정 중” 배지 표시 → **상세 계획 화면**
3. **AI 채팅** 추천 카드 클릭 → **지도** 임시 핀 생성 + “수정 중” 상태 자동 활성화 → **상세 계획 화면**
4. **지도**에서 “수정 중” 배지 클릭 또는 상세 계획 버튼 → **상세 계획 화면**
5. **상세 계획** 확정 → 확정핀 변환 + “수정 중” 상태 해제 → **내 일정**으로 유도
6. Map ↔ Chat 간 **currentEditingPlan** 상태 실시간 동기화 (양방향)
