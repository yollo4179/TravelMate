# v1_local·v2 문맥 생성 및 검색 진단

2026-10-31 · 실행 기준 코드 `b2c218034537a74f7bc652dcd688cf36240789d1`

v2는 일부 문맥과 장소 순위를 개선했지만 **현재 자료로 전반적인 품질 개선을 확정할 수 없다.**
다른 공원의 경관을 대상 장소에 붙인 사례 1개와 구간 주제를 앞부분 요약으로 바꾼 사례 4개가 있다. 두 집계는 중복된다.
목표 장소의 순위가 오른 것과 올바른 근거를 찾은 것은 다르다.

## 범위와 조건

- 청담도로공원 한 장소의 기존 응답 9쌍, 동일 원문 22구간을 검수했다. 표준 v1 재실행이 아니라 `v1_local_2d365e87c12314cb`와 v2의 비교다.
- 원문·분할·모델 선택·effort·8192 출력 한도·스키마가 같고 지시문만 다르다. 실제 응답 모델은 양쪽 모두 `perplexity/sonar`, 재검증 규칙은 `contextual-validation-v2`다.
- 원문에서 질문 26개와 구간 기준을 먼저 고정했다. 이전 대화에서 v2 사례 3개를 보았으므로 블라인드 검수가 아니다. 독립적인 사람 검수도 아니다.
- 22개는 원문으로 답할 수 있는 질문, 3개는 다른 공원/전체 통계를 잘못 귀속하는 질문, 1개는 혼합 장소 스트레스 질문이다.
- 449개 장소의 동일 스냅샷을 임시 스키마 두 개에 복제했다. 9쌍은 각각 해당 묶음만 subject+TourAPI로 색인해 비교했다. 다른 448개 장소는 기존 벡터·설명을 유지했다.
- 실제 GPU 모델은 `BAAI/bge-m3`(revision `5617a9f61b028005a4858fdac845db406aefb181`), `BAAI/bge-reranker-v2-m3`, RTX 4050 Laptop GPU다. 리랭킹은 batch 8·autocast_fp16이다.
- 최신 `KafkaRuntime._complete_recommendation`을 호출해 pgvector 후보 30개·장소별 근거 1개·실제 리랭킹·결과 20개를 실행했다. 결과 저장은 파일로 대체했다.

Q21은 임베딩 단계에서 목표 장소가 4위였지만, 장소별로 단 하나의 근거만 넘기기 때문에 실제 혼잡 안내 P08-S02가 리랭커에 도달하지 못했다.
프롬프트만 개선해 해결되지 않는 후보 근거 선택 문제다. 이번 평가에서 검색 구조를 바꾸지는 않았다.

잘못된 시설/면적 귀속 질문 3개에서 제외해야 할 원문이 노출된 횟수는 양쪽 모두 0회다.
그러나 대상 장소 자체는 모두 1위로 반환됐다. 현재 순위 반환은 전제의 참·거짓을 판정하거나 답변을 거절하는 기능이 아니다.
최종 답변을 생성하지 않았으므로 이것을 답변 환각 3건으로 계산하지 않는다.

## 문맥 검수

v2의 명확한 개선은 P03-S02의 편의시설 개선 제안과 현존 시설 구분, P04-S01 주소·연락처의 적절한 subject 귀속이다.
P04-S02에서는 비·연휴·촬영 대기 조건을, P09-S03에서는 낡은 화장실과 휴지 관찰을 더 구체적으로 남겼다.

다음 문제는 남아 있다.

1. **P09-S02 장소 귀속 오류:** 실제 구간은 삼성해맞이공원의 데이트 소감과 청담도로공원 주차장 주소다. v2는 앞 구간의 삼성정·깨끗한 조경·한강·롯데타워 경관을 요약한 뒤 `청담도로공원/subject`로 붙였다. 이는 mentioned를 정상 처리하는 코드 수정과 별개의 모델 귀속 오류다.
2. **구간 주제 대체 4개:** P01-S03은 운전자 모임·주차 대신 앞부분 조성·시설, P05-S02는 야경·쉼터 대신 앞부분 화장실, P05-S03은 주차·진출입 안전 대신 앞부분 경관을 요약했다. P09-S02도 앞 구간으로 대체됐다. 대부분 같은 문서의 실제 내용이지만 해당 chunk의 검색 문맥으로는 부적절하다. v1에도 P03-S02 한 곳에서 같은 유형이 있었다.
3. **혼합 장소 청크:** P09-S01에는 대상 주차장과 삼성해맞이공원 경관이 같이 남는다. 문맥이 이동을 설명하더라도 원문 전체가 임베딩·리랭킹에 들어가므로 잘못된 추천 근거가 될 위험이 있다.

P03-S03·P06-S01의 다른 공원 설명과 P08-S01의 혼합 장소 경관은 v2가 mentioned로 보존하고 색인에서 제외했다.
기존 v1도 빈 귀속으로 제외했기 때문에 이 변경을 검색 성능 개선으로 세지는 않는다.
추가된 검색 후보 2개 중 주소 구간 하나는 타당하고 P09-S02 하나는 잘못된 경관 귀속이다. 15→17개 증가는 그 자체로 개선이 아니다.

## 다음 변경의 근거

v2 원본과 이번 결과를 보존한 상태로 후속 프롬프트 버전에서 구간 주제 유지·다른 장소 귀속을 강화할 근거가 생겼다.
동일 문서 전체를 참고할 수 있게 한 규칙을 없애기보다, 추가 배경이 인용 구간의 주제를 대체하지 않는지 검증해야 한다.
혼합 장소를 하나의 넓은 청크로 묶은 상태의 한계도 있다. 모델 지시문만으로 해결됐다고 간주하지 않는다.
장소당 근거 복수 선택은 프롬프트 비교와 분리된 검색 구조 실험으로 다뤄야 한다.

- 평가 집계 검증 테스트 6개 통과. 원래 서비스의 47개 단위 테스트 결과와는 별도다.
