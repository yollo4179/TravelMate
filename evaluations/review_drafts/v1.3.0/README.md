# v1.3.0 검토 메모 초안

- review_notes_filled_v1.3.0.csv: 검수표 273행 전체의 review_notes 작성본
- review_notes_rows_002_100.csv: 앞서 요청한 Excel 2~100행만 담은 99항목 발췌
- review_notes_by_question.md: 질문 100개로 묶은 읽기 쉬운 설명
- metadata.json: 원본 버전·해시·검토 주체·변경 범위
- [evaluation_review_criteria.md](evaluation_review_criteria.md): Ragas 0.4.3 기준으로 보완한 리뷰 판정·검색/생성 평가 기준

리뷰 메모 개정 2에서는 273행 전체에 원본 CSV 행 번호, 질문 조건, 스냅샷 원문 인용, 생성 답변 검수 기준을 반영했습니다. 답변 불가·추가 질문 20문항에는 통과·실패 행동을 적었습니다. 문서의 질문 번호와 CSV 행 번호는 다르며, 예를 들어 CSV 19행은 약현성당의 로마네스크 양식 문항입니다.

0~3점은 장소의 검색 적합도입니다. 실제 답변의 정확성·근거 충실성에 대한 Ragas 점수가 아니며, 리뷰 메모를 기대 답변이나 실제 시스템 출력으로 그대로 사용하지 않습니다.

기존 relevance, 질문, 조건, 근거, 사람 검수자, 검수 상태는 변경하지 않았습니다. 문서의 의견은 AI 검토 초안이며 사용자가 읽고 확정할 수 있도록 작성했습니다. human_reviewer는 사용자 본인이 실제 검수한 뒤 기입합니다.

원본 review.csv에 작성 중인 메모가 있다면 이 파일로 통째로 덮어쓰지 말고 case_id + place_id로 비교해 필요한 메모만 가져오세요. 이 CSV는 원본 빌더의 파생 파일과 구분되는 검토용 사본입니다. 검수 메모를 작성 원본에 반영하기 전 --build를 실행하면 메모가 사라질 수 있습니다.

내용은 업로드한 관광 데이터 스냅샷에 근거합니다. 실제 운영·예약·혼잡·현장 상태나 실제 모델 답변을 채점한 것은 아닙니다.
