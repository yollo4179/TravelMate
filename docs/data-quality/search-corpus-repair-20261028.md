# 검색 코퍼스 가공 수정 및 적용 준비

기존 449개 장소의 동결 스냅샷과 기존 평가 라벨을 유지한 상태에서 수집·가공 코드를 수정했다.
실제 DB 갱신, 외부 TourAPI 호출, 새 임베딩 생성과 모델 성능 재측정은 아직 실행하지 않았다.

## 수정한 동작

| 문제 | 변경된 동작 |
|---|---|
| 입장료·시설·예약·해설 정보가 원본에 있어도 검색 설명에서 제외됨 | 제목과 본문이 유효한 추가 안내를 모두 반영하고 중복을 제거한다. 제목 공백과 HTML도 정리한다. |
| 소개문이 없으면 추가 안내가 있어도 임베딩을 생략함 | 소개문 또는 유효한 추가 안내가 있으면 임베딩한다. 분류명만 있는 레코드는 임베딩하지 않는다. |
| 국내 장소에 명백히 잘못된 좌표가 들어갈 수 있음 | 누락·NaN·무한대·국내의 넓은 허용 범위 밖 좌표를 색인 전에 차단한다. 원본은 미처리 상태로 남겨 확인할 수 있다. |
| 수집 호출 실패가 0건 반환처럼 처리됨 | HTTP·파싱 오류, 유효하지 않은 totalCount, 비어 있는 결과 페이지, 식별자 없는 항목은 오류로 중단한다. 정상적인 0건 결과는 허용한다. |
| 이미 저장한 장소는 다시 가공해도 갱신되지 않음 | TourAPI 콘텐츠 ID 기준으로 장소 ID를 유지하며 설명·좌표·임베딩을 갱신한다. 원본을 다시 저장하면 가공 대기 상태로 전환한다. |

좌표 검사는 국내 수집 자료의 명백한 이상값을 찾는 범위 검사다. 정확한 시·군·구 경계 검증이나 올바른 좌표의 보정 기능은 아니다.
보관된 입장료와 운영 안내는 수집 당시의 사실이며 현재 영업·특정 주말의 운영을 보증하지 않는다.

## 네트워크와 DB 없이 확인한 결과

실제 Java 가공 코드로 `Evaluation/datasets/v1.4.0/source/snapshot.json`을 읽어 미리보기를 생성했다.

- 전체 449건, 넓은 국내 좌표 범위를 통과한 441건, 좌표 확인이 필요한 8건.
- 추가 정보 반영 또는 HTML 정리로 검색 설명이 바뀐 항목은 394건.
- 원본의 추가 안내 중 제목·본문이 유효한 필드가 있는 장소는 383건.
- 청담도로공원은 기존 9자 설명에 원본의 팔각정·화장실·주차 안내를 추가한다. 숲·한강 조망 등 원본에 없는 정보는 생성하지 않는다.
- 풍납백제문화공원에는 원본의 입장료 안내를 추가한다. 빈약한 소개문 자체가 풍부해졌다고 보지는 않는다.
- 기존 스냅샷 SHA-256과 평가 라벨의 순위 공개 전 SHA-256이 그대로임을 확인했다.
- 데이터 가공·좌표·색인·수집 실패 처리에 관한 회귀 테스트 29개가 통과했다.

미리보기: `Evaluation/runs/search/search-holdout-v1.0.1/data-quality-audit-20261028/rebuild-preview-v2.json`.
미리보기에는 현재 설명과 수정 후 설명, 좌표 상태가 함께 들어 있다.
이미 확인한 결과를 실수로 덮어쓰지 않도록 출력 파일이 존재하면 미리보기 실행을 거부한다.

## 실제 반영 순서

1. 운영 대상 DB의 places와 tour_api_raw를 임베딩 벡터까지 포함해 백업한다. 기존 동결 스냅샷은 벡터 자체의 백업을 대신하지 않는다.
2. 좌표 오류 8건을 확인 목록으로 관리한다. 검증된 출처로 올바른 좌표를 확보하기 전에는 임의 좌표로 바꾸지 않는다. 기존 DB의 잘못된 레코드는 새 수집 차단만으로 자동 교정되지 않는다.
3. 수정한 서버 버전에서 확인된 원본을 가공 대기 상태로 돌리고 재색인한다. 이번 변경은 이미 processed_at이 설정된 449건을 자동으로 재처리하지 않는다.
4. 선유도공원·문화비축기지·낙산공원·보라매공원·서래섬·봉은사·정동제일교회의 수집 범위를 확인한다. 동결 코퍼스에 동일 명칭 레코드가 없는 것은 확인했지만 당시 누락 원인은 아직 확정하지 않았다. 수집 재개 시 실패 페이지와 완료 범위를 남긴다.
5. 변경된 코퍼스를 새 버전으로 동결하고 검색 결과를 다시 수집·검수한다. 이번 449개 코퍼스에서 얻은 7문항 잠정 점수를 새 코퍼스의 점수로 재사용하지 않는다.

`Server/TravelMate`에서 검증 명령:

```powershell
.\gradlew.bat --offline --no-daemon test --tests '*TourPlaceDataQualityTest' --tests '*TourPlaceIndexingQualityTest' --tests '*TourApiCollectionQualityTest'
```

추가 미리보기는 같은 디렉터리에서 `previewTourPlaceData` 작업에 `-PsnapshotPath`와
아직 존재하지 않는 `-PpreviewOutput` 경로를 지정해 실행한다. 이 작업은 Spring 서버를 시작하지 않는다.
