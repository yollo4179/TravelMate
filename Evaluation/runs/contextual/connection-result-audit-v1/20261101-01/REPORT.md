# 저장된 ‘주변 관광지와 연결된 곳’ 검색 결과의 원문 판정

판정일: 2026-11-01 · 평가 대상: 커밋 `b35afbab`의 저장 비교 · 질문: `주변 관광지와 연결된 곳`

**변경 결과에서 A보다 앞선 27개와 A 모두 원문상 연결 근거가 있다. 도보·거리 조건을 추가하지 않는 이번 판정에서 A가 28위라는 사실만으로 순위 오류라고 판정하지 않는다.**

기존·변경 검색의 상위 20개는 모두 차량 전용 연결 근거를 갖고 있었고 도보 금지가 보존돼 있었다. 같은 판정표로 계산한 Precision@5·10·20과 NDCG@10은 두 방식 모두 1.0이다. 이 한 질문에서 상위 결과의 적합성 개선은 확인하지 못했다.

전체 30개에서는 두 방식 모두 연결 근거가 없는 청담도로공원 결과가 남는다. 변경 결과의 B공원은 다른 근거에 긍정 이동 경험이 있지만 대표 description은 공사로 이동에 실패한 기록을 선택했다. 이 문제는 장소 관련도와 대표 근거 선택을 나눠 확인했다.

**판정 범위와 기준**

새 검색·임베딩·리랭킹·LLM 호출·외부 웹 확인 없이 저장 결과만 사용했다. 질문에 다음 조건을 추가하지 않았다.

- 도보 이동, 정해진 거리·시간·반경, 현재 위치
- 특정 출발지·도착지, 양방향 통행, 편리함·안전함·무장애 이동
- A가 차량 연결 장소보다 높은 순위여야 한다는 요구

다른 공원으로 이동 가능하거나 실제로 이동한 경험을 직접 뒷받침하면 2점으로 판정했다. 도보와 차량을 같은 등급으로 두되 차량 전용·계단·통행 금지는 보존해야 한다. 경로를 언급하지만 공사 차단·이동 실패만 설명하면 1점, 전달된 구간에 다른 관광지와의 연결 내용이 없으면 0점이다. 2점 이상을 긍정 연결 근거로 집계한다.

‘주변’에 관한 실제 지리적 근접성이나 합성 장소의 실재성을 확인한 것은 아니다. 구체적 거리 조건을 만들지 않고 보존된 원문 속 다른 공원과의 연결을 판정했다. 과거 이동 경험이 현재도 가능한지, 공사가 현재도 진행 중인지는 확인하지 않았다.

**무엇을 대조했나**

- 기존·변경 각각 30개, 총 60개 결과를 확인했다. 두 방식의 합집합은 31개 장소다.
- 실제 전달된 고유 청크 33개를 원문 보존 파일과 대조했다. A보다 앞선 27개도 각각 별도 source_id/source_version/chunk_id로 확인했다.
- 실제 원문의 source_span과 청크 텍스트, 인용·관계 방향·조건, 반환 장소의 관계 참가 여부, 저장 description이 사용하는 표현을 검사했다.
- 실제 자료는 보존된 sources.json을 사용했다. 합성 차량 자료는 실행 당시와 같은 고정 fixture 함수를 재구성해 저장 결과와 출처 ID·버전·원문을 대조했다. 새 모델 출력으로 원문을 보충하지 않았다.
- 비교 결과의 원본 해시는 기존 publication 기록과 일치했다. 보존 파일을 변경하거나 순위를 다시 계산하지 않았다.

이번 검수자는 순위와 검색 방식 정보를 본 동일 에이전트다. 독립 인간 평가나 블라인드 평가가 아니다. 원문을 읽고 동일 의미 문장별 등급을 정한 뒤 33개 패킷에 연결했으며 모델 점수를 의미 판정 기준으로 사용하지 않았다.

**A보다 앞선 27개는 왜 적합한가**

변경 결과의 1~27위는 모두 연결공원 합성 자료다. 각 장소의 원문은 다음 인용을 포함한다.

> B공원까지 차량으로만 이동할 수 있으며 도보 통행은 금지된다.

각 관계의 방향은 해당 연결공원 → B공원이다. 원문에서 차량 연결을 명시하고, 변경 검색의 대표 description에도 차량 전용과 도보 금지가 그대로 남아 있다. B공원 → 연결공원이라는 역방향 이동이나 도보 가능으로 바뀐 표현은 발견하지 못했다.

이 자료들은 이전 도보 질문에서는 방해 사례였지만, 이번 질문에는 도보 조건이 없다. 따라서 동일한 자료를 이번 질문의 오답으로 유지할 근거가 없다. 각각 2점으로 인정한다. 차량으로 이동할 수 있다는 이유만으로 가깝거나 편리하다고 해석하지도 않았다.

A공원에는 관람 후 B공원으로 걸어갈 수 있다는 인용과 A에서 계단을 내려가 B까지 걸어간 경험이 있다. A 역시 2점이다. 도보를 선호한다는 조건이 없으므로 A를 차량 연결 장소보다 높은 등급으로 두지 않는다. 기존 A의 30위와 변경 A의 28위 모두 이 동등 관련도 안의 순서이며, A만을 정답으로 놓는 지표는 사용하지 않는다.

27개는 서로 다른 장소 ID지만 이동 인용은 동일한 템플릿이다. 장소 중복 제거와 별개로 결과의 의미 다양성이 낮다는 특징은 기록했다. 이번에는 다양성 가중치나 재정렬 정책을 추가하지 않았다.

**전체 결과에서 남은 근거 문제**

| 대상 | 기존 순위 | 변경 순위 | 장소의 관련도 | 대표 근거 판정 |
|---|---:|---:|---|---|
| A공원(101) | 30 | 28 | 두 방식 모두 긍정 연결 근거 있음, 2점 | 두 방식 모두 A→B 도보 연결, 2점 |
| B공원(202) | 미반환 | 29 | 변경 결과의 보조 근거에 A→B 계단 이동 경험이 있어 2점 | 대표는 공사 차단·이동 실패 기록으로 1점 |
| 청담도로공원(394) | 29 | 30 | 전달된 두 구간에 연결 근거 없음, 0점 | 흙길이 보인다는 관찰로 0점 |

B의 대표 인용에는 ‘공사로 길이 막혀 돌아왔다’는 부정 조건이 그대로 남는다. 이를 이동 가능으로 바꿔 쓴 왜곡은 발견하지 못했다. 다만 이 부정 기록만으로 이용 가능한 연결을 긍정 추천할 수는 없다. 긍정 이동을 설명하는 보조 근거와 대표 선택을 구분해야 한다. 두 기록의 시점 관계는 알 수 없어 현재 개방 상태로 합치지 않는다.

청담도로공원의 선택 구간은 흙길 관찰과 공원이 있다는 언급이다. 다른 관광지에 이어진다는 내용은 없다. 원문 문서의 제목이나 metadata에 보존된 다른 구간을 가져와 이 두 선택 근거를 연결 근거로 바꾸지 않았다. 이는 청담도로공원이 실제로 다른 장소와 연결되지 않는다는 판정이 아니라, 이번에 전달한 근거가 질문을 뒷받침하지 않는다는 판정이다.

**같은 판정표로 비교한 지표**

장소 관련도 정답표는 두 방식이 실제 전달한 근거의 합집합을 사용했다. 31개 장소 중 30개는 적어도 하나의 긍정 연결 근거가 있고, 청담도로공원만 전달된 근거에서 연결을 확인할 수 없다. 차량 연결과 도보 연결을 모두 2점으로 처리한 같은 정답표로 기존 ranking_metrics를 계산했다.

| 항목 | 기존 | 변경 |
|---|---:|---:|
| Precision@5 | 1.000 | 1.000 |
| Precision@10 | 1.000 | 1.000 |
| Precision@20 | 1.000 | 1.000 |
| NDCG@10 | 1.000 | 1.000 |
| 상위 20개 대표 근거의 긍정 연결 충족 | 20/20 | 20/20 |
| 전체 30개 중 실제 전달 근거에 긍정 연결이 있는 장소 | 29/30 | 29/30 |
| 전체 30개 중 대표 근거가 긍정 연결을 뒷받침하는 장소 | 29/30 | 28/30 |
| 판정 풀 안의 Recall@30 | 29/30 | 29/30 |
| A보다 앞선 결과 중 긍정 대표 근거가 있는 수 | 28/29 | 27/27 |

기존 검색은 연결공원12(1012)를 반환했고 변경 검색은 대신 B공원을 반환했다. 둘 다 긍정 연결 근거가 있으므로 장소 관련도 지표는 이 교체를 품질 개선으로 세지 않는다. B의 대표 근거가 차단 기록인 문제는 별도 근거 적합성 집계에 나타난다.

Recall의 분모는 판정한 합집합의 관련 장소 30개다. 전체 43개 색인 장소나 운영 전체의 관련 장소를 모두 판정한 값이 아니다. 상위 결과가 같은 합성 템플릿으로 채워져 Precision과 NDCG가 포화되므로, 1.0을 일반 의미 검색 품질 100%로 해석하지 않는다.

**이 판정으로 내릴 수 있는 결론**

이번 ‘연결’ 질문에서는 A 앞의 차량 연결 27개를 오답으로 볼 근거가 없으며, A의 28위 자체도 실패 지표로 사용할 수 없다. 같은 기준에서 상위 결과의 적합성은 기존과 같았고 개선은 입증하지 못했다.

동시에 전체 30개에는 근거 부족 결과가 남으며, 장소가 관련 있어도 부정 조건을 담은 근거가 대표로 선택되는 경우를 확인했다. 이 두 항목을 별도 문제로 기록했다. 이를 해결하기 위해 검색이나 리랭킹 기능을 이번에 변경하지는 않았다.

평가 자료는 하나의 넓은 질문과 반복된 합성 연결 자료 중심이다. 거리·모드가 다양한 실제 질문으로 일반화할 수 없다. 신규 검색·모델 호출·운영 DB 반영은 모두 0회이고, 애플리케이션 코드도 수정하지 않았다. 기존 156개 테스트를 이번 의미 판정의 성공 근거로 사용하지 않았다.

재현은 같은 보존 아카이브를 대상으로 prepare_evidence.py를 실행하고, 확정한 reviewed-groups.json으로 score_review.py를 실행한다. 전자는 출처·원문 무결성을 검사하고 후자는 수동 판정표의 순위 지표를 계산한다. 새 의미 판정을 자동 생성하는 judge 모델은 없다.
