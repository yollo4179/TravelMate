## 실패 원인: 인용의 정확 일치 (palaces-01)

모델이 인용 두 개 중 하나에서 원문의 한자 병기를 뺐다.

| | 문구 |
|---|---|
| 원문 | `창경궁(昌慶宮)은 성종이 세 명의 대비를 위해 옛 수강궁에 창건한 궁이다.` |
| 모델 인용 | `창경궁은 성종이 세 명의 대비를 위해 옛 수강궁에 창건한 궁이다.` |

- 인용은 원문의 연속 문자열과 정확히 일치해야 한다. 그래서 답변 전체가 거부되고 대체 문구로 바뀌었다.
- 다른 인용 하나와 대사 3컷의 내용은 원문과 맞았다.
- r1에서는 같은 문항이 정확히 인용해 통과했다. 모델 출력이 실행마다 달라지면서 드러난 문제다.
- 이전 단일 LLM 실측에서도 보였던 인용 처리 문제와 같다(공백 차이, 다른 후보 인용). 처리 방식은 아직 결정하지 않았다.

대체 문구도 문제다. 대체 문구 "설명을 완료하지 못했습니다. 확인된 서버 결과와 작업 상태를 확인해 주세요."가 LiLi의 대사 자리에 그대로 나왔다(`ConversationAnswerRenderer`).
여기에 "서버"라는 내부 표현이 들어 있어 `no_internal_terms`에서도 실패했다.
