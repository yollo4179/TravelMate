평가 트랙을 60/20/20개로 분리하고 직접 정답만을 위한 `strict_relevant_place_ids`를 추가했습니다. 관련도·ID·후보 수·출처 메타데이터·모든 참조 장소의 분할·작성 원본/CSV/manifest와 파생 파일의 일관성 검사 및 회귀 테스트를 보완했습니다.

생성 JSON/JSONL/CSV 레코드를 LF로 고정하고 원본 스냅샷 바이트는 보존했습니다. `run.sh`로 호스트 Python 없이 Docker에서 검증·테스트·재생성을 실행할 수 있습니다.

사람 검수 대기 상태를 유지합니다. 이번 수정으로 전체 관련 장소의 완전성이나 검색/RAGAS 성능을 확정하지 않았습니다.
